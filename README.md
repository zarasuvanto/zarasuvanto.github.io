# zarasuvanto.github.io

Video portfolio of Zara Suvanto. Live at https://zarasuvanto.github.io

- `index.html` – the whole site. To add or change a video, edit the `WORK` list near the bottom of the file.
- `videos/` – web-compressed MP4s
- `posters/` – thumbnail frames for each video
- `img/`, `files/` – logo, headshot, resume
